# אולי יצמח מזה משהו

מיצג אינטראקטיבי לבחירות לכנסת ה־26. כל פתק שנכנס לקלפי הופך לפרח. 30 הפתקים הראשונים מצמיחים זר מהקלפי. מהפתק ה־6 (`sprout`) מתחילים לצוץ איים מסביב, וכל פתק מוסיף להם חופן פרחים. ב־60 פתקים (`goal` ב־`config.js`) כל הקרקע ירוקה. המונה חי ומשותף לכל המבקרים. כל מבקר יכול להכניס פתק אחד, עד שהוא מרענן את הדף.

## פרסום ב־GitHub Pages
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, תיקייה `/ (root)` → Save**.

כל עדכון ל־`main` עולה לאוויר תוך דקה־שתיים. הכתובת: `https://aki12234-lgtm.github.io/2026_Elections/`.

## Firebase
- הפרויקט: `kalpi-e4081`. ההגדרות כבר ב־`config.js`.
- הכללים מ־`database.rules.json` צריכים להיות מודבקים בלשונית **Rules** של Realtime Database.
- **איפוס המונה:** ב־Firebase Console → Realtime Database → Data, מוחקים את `votes/count`. הדף עצמו לא יכול לאפס, הכללים חוסמים את זה.

## לוח הבדיקה
מוסיפים `?review` לכתובת. בלוח יש מצבים מוכנים, סליידר, "כל התהליך", רוח ופונטים. כל מה שעושים בלוח הוא סימולציה מקומית ולא נוגע במונה האמיתי. הכפתור "חזרה לחי" מחזיר למונה האמיתי.

## מגבלות ידועות
- ההגבלה של פתק אחד היא לטעינת דף. רענון מאפשר עוד פתק, כמו שהוגדר.
- אין הגנה מבוט שקורא ל־API ישירות. אם זה יהפוך לבעיה, אפשר להוסיף Firebase App Check.

## הפתק והשיתוף
- במחשב הפתק עוקב אחרי העכבר ונכנס לקלפי רק בקליק על הקלפי (קליק במקום אחר מנער אותו). בטלפון הוא מחכה ליד הקלפי: נוגעים בו, נוגעים בקלפי, או גוררים אותו פנימה. הוא תמיד באותה פרספקטיבה כמו בחריץ.
- על כל פתק כתוב מסר (תקווה, שלום, צמיחה...). הרשימה ב־`MESSAGES` בתוך `index.html`.
- כפתור "שתפו את הקלפי": במחשב למעלה משמאל בגובה הכותרת, בטלפון בשורה התחתונה ליד המונה. בטלפון נפתח חלון השיתוף, במחשב הקישור מועתק.
- המונה מוסתר עד שמגיע המספר האמיתי, כך שלא רואים 0 בכניסה.
- במכשיר חלש הרוח נכבית אוטומטית והגינה נעצרת, כדי שהדף יישאר חלק.
